# Clinical Simulation and Feedback

A 30-week project for the *Agentic AI & RAG Engineering* programme. The capstone will provide an educational clinical simulation in which a learner interviews a synthetic patient, submits a diagnosis, and receives feedback grounded in a published clinical case. The conversation is generated by a language model and is not a recording of a real consultation.

The platform is intended for medical and nursing students, junior residents, and their instructors. It is a learning tool only: it will not diagnose real patients, recommend treatment, or connect to live patient records.

## Dataset

Phase 1 will use 100 manually curated cases from the `AGBonnet/augmented-clinical-notes` dataset. Selected cases must contain enough history and symptom detail for an interview and have a clear final diagnosis in the source note. Cases with incomplete conversations, prompt leakage, conflicts with the full note, or an early diagnosis reveal will be excluded.

## Structure

- `src/` — application code
- `docs/adr/` — Architecture Decision Records (one per major design
choice)
- `docs/runs/` — saved LLM outputs for evidence and reference

## Project Setup

This project uses `uv` for dependency management. To set it up:

1. Run `uv sync` to install the dependencies and create the virtual environment.
2. Add a `.env` file containing a valid OpenAI API key.
